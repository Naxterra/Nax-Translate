# Must never happen

Draft, waiting for the owner's approval. Each item names the tests that cover it, or says that no test covers it yet.

| # | The app must never | Covered by |
|---|---|---|
| 1 | leave the settings file half-written or replace good settings with a broken file. | `ConfigTests::save_cannot_write_original_settings_file_unchanged`, `ConfigTests::settings_saved_and_reloaded_with_no_temporary_file_left` |
| 2 | crash or refuse to start because the settings file is damaged. | `ConfigTests::damaged_settings_file_loads_defaults_without_crashing` |
| 3 | store login tokens on disk in plain text. | `ConfigTests::login_tokens_saved_encrypted_never_in_plain_text`, `ConfigTests::old_plain_text_tokens_migrated_and_removed_from_file` |
| 4 | leave the deepl:// link handler pointing at this app after a login, even if the app crashed during the login. | `SchemeHandlerTests::login_without_existing_handler_leaves_no_registry_keys_behind`, `SchemeHandlerTests::second_login_after_crash_still_restores_real_original_handler` |
| 5 | overwrite or delete the official DeepL app's link handler or other registry keys it did not create. | `SchemeHandlerTests::login_with_existing_handler_restores_original_command`, `SchemeHandlerTests::existing_scheme_key_without_command_gets_only_created_keys_removed`, `SchemeHandlerTests::existing_scheme_key_without_url_protocol_gets_added_value_removed`, `SchemeHandlerTests::start_without_unfinished_login_changes_nothing` |
| 6 | hang forever on a dead connection after a network switch or a dropped network. | `NetworkTests::network_change_mid_request_moves_request_to_fresh_connection`, `NetworkTests::request_hangs_past_attempt_limit_then_retried_and_succeeds`, `NetworkTests::every_attempt_fails_reports_offline_instead_of_hanging` |
| 7 | freeze or go blank when the network changes. The window must stay usable and say that it is offline. | No automated test. The owner checked it by hand in the running app on 2026-10-29, and translation kept working after a network switch. |
| 8 | throw away a valid login only because DeepL could not be reached. | `NetworkTests::token_refresh_while_offline_reports_offline_so_login_is_kept` |
| 9 | show the translation of older text after newer text was typed, or let an old answer change newly selected languages or engine options. | `WindowTranslationTests::late_old_response_cannot_replace_new_result`, `WindowTranslationTests::editing_text_cancels_request_even_when_new_text_cannot_translate`, `WindowTranslationTests::changing_translation_selection_cancels_request_before_debounce`, `WindowTranslationTests::old_detection_cannot_override_newly_selected_target`. The tests use hidden WPF controls and fake services. |
| 10 | read browser cookies, saved passwords or other programs' data. | No test. The code that did this was removed in 1.1.0. |
| 11 | send the user's text anywhere other than the selected engine: DeepL, Claude through Claude Code, or ChatGPT through Codex CLI. | `WindowTranslationTests::chatgpt_routing_uses_selected_tone_and_never_contacts_other_engines`, `WindowTranslationTests::chatgpt_disconnect_blocks_sends_and_tones_stay_independent` use fake services to check ChatGPT routing. Live service behavior is a separate smoke check. |
| 12 | swallow key presses or break Ctrl+C in other programs through the Ctrl+C+C keyboard hook. | No test yet. |
| 13 | leave the "Start with Windows" entry behind after it was switched off. | `StartupTests::start_with_windows_switched_off_removes_entry_and_keeps_other_programs`, `StartupTests::start_with_windows_switched_off_when_never_on_changes_nothing`, `StartupTests::start_with_windows_switched_off_also_removes_entry_under_old_app_name` |
| 14 | accept a login link that does not belong to the login it started, for example one sent by another program. | `LoginCallbackTests::login_callback_with_wrong_state_ignored`, `LoginCallbackTests::login_callback_without_running_login_ignored`, `LoginCallbackTests::malformed_login_callback_ignored_without_crash` |
| 15 | leave its files, its "Start with Windows" entry or a login's deepl:// handler behind after it was uninstalled, or delete the user's settings without asking. | No automated test. The uninstaller runs the app with `--uninstall-cleanup`, which uses the code covered by items 4, 5 and 13. |
| 16 | lose the settings or the login of an older version when it is updated, overwrite settings that already exist under the new name, or keep a "Start with Windows" entry that points at the old program file. | `ConfigTests::settings_of_old_app_name_moved_with_login_intact`, `ConfigTests::settings_of_old_app_name_never_replace_existing_new_settings`, `StartupTests::old_start_with_windows_entry_replaced_by_one_for_renamed_app`, `StartupTests::start_without_old_entry_does_not_switch_on_start_with_windows`, `ConfigTests::settings_of_nax_deepl_moved_before_older_settings_and_older_left_alone`, `StartupTests::start_with_windows_entry_of_nax_deepl_replaced_by_one_for_nax_translate`, `StartupTests::start_with_windows_switched_off_also_removes_entry_of_nax_deepl` |
| 17 | start the user's own Claude Code hooks, plugins, MCP servers or tools, or save a Claude Code session, when it translates with Claude. | Partly. `ClaudeCliTests::claude_run_skips_hooks_tools_and_saved_sessions` checks that the app passes the safe-mode arguments. Whether the real tool then loads no hooks has no automated test. It was checked by hand on 2026-11-03 with Claude Code 2.1.302, whose debug log showed that no hooks were registered. |
| 18 | keep a Claude request or a waiting Claude process running after newer text was typed, after DeepL was picked again or after the app exits, or start a request for text that is already outdated or over the character limit. | `ClaudeCliTests::translation_cancelled_while_running_kills_claude_process`, `ClaudeCliTests::switching_back_to_deepl_ends_waiting_claude_process`, `ClaudeCliTests::claude_already_cancelled_translation_never_starts_tool`, `ClaudeCliTests::text_over_character_limit_never_sent_to_claude`. Window handlers are covered with fake processes by `WindowTranslationTests::changing_claude_options_stops_active_process_immediately` and `WindowTranslationTests::stopping_window_kills_active_and_waiting_claude_processes`; the latter also checks that repeated exit cleanup is safe. |
| 19 | bill Claude translations to an API key or another endpoint instead of the signed-in subscription. | `ClaudeCliTests::api_key_variables_removed_so_claude_uses_the_subscription` |
| 20 | let one Claude translation see the text of an earlier one. | `ClaudeCliTests::each_claude_process_translates_only_once_so_no_text_carries_over` |
| 21 | leave a cut-off Claude translation in the box after the request failed or was stopped, where Copy would take it as complete. | No automated test for the window. Since 1.2.0 the window shows a Claude translation only when it is complete, so a part of an answer is never shown. A stopped or silent request ends with an error instead of a result, covered by `ClaudeCliTests::claude_silent_for_too_long_stopped_and_reported_as_timeout` and `ClaudeCliTests::translation_cancelled_while_running_kills_claude_process`. |
| 22 | leave the program files, shortcuts or "Start with Windows" entry of the old name Nax-DeepL behind after an update to Nax-Translate, or delete any file it did not install itself. | No automated test. Checked by hand on 2026-11-03 by installing Nax-DeepL 1.1.0 and updating it with the 1.2.0 setup, silently, twice: into a folder the user chose that also held other files (the other files stayed, only the Nax-DeepL files went, the start entry moved) and into the default folder (the update moved to the Nax-Translate folder, the old folder was removed, the start entry moved). A third run used a folder shared with another program that already owned unins000: the old setup named its uninstaller unins001, and the update removed exactly that one, kept the other program's unins000 and moved a DeepL-Translator start entry. The setup deletes old files by name only, deletes only the uninstaller named in the old uninstall entry, and removes the old folder only when it is empty. |
| 23 | send text to Claude, or keep a Claude Code process running, while Claude is disconnected in the menu. | `ConfigTests::claude_disconnected_stays_disconnected_after_restart` checks that the choice is kept. `WindowTranslationTests::disconnected_claude_sends_nothing` checks the send guard, and the disconnect case of `WindowTranslationTests::changing_claude_options_stops_active_process_immediately` checks that the menu stops both active and waiting fake processes. |
| 24 | show a black or empty window when it is opened, for example after it was started hidden, the screen was locked or the computer slept. | No automated test. Since 1.2.0 the app draws without the graphics card and repaints the window when it is shown, after unlocking and after resume. Checked on 2026-11-04 by capturing the window after a start with --show, after a hidden start followed by a second start, after minimizing to the tray and after closing and reopening. |
| 25 | send text to ChatGPT while disconnected, use an API-key sign-in, show an incomplete answer as complete, retain an outdated request or save a translation conversation. | `ChatGptCliTests::api_key_or_missing_login_never_sends_a_translation`, `ChatGptCliTests::failures_partial_answers_and_tool_calls_are_never_returned`, `ChatGptCliTests::requests_disable_saved_sessions_user_configuration_and_tools`, `ChatGptCliTests::cancellation_reaches_runner_and_removes_the_request_directory`, `ChatGptCliTests::real_child_process_is_terminated_when_cancelled`, `WindowTranslationTests::changing_chatgpt_options_cancels_immediately_and_ignores_late_answers`, `WindowTranslationTests::chatgpt_disconnect_blocks_sends_and_tones_stay_independent`. CLI configuration tests check supplied flags, rather than proving every future CLI version's behavior. |
| 26 | reuse another translation's conversation, enable inherited tools or telemetry, retain cached text after disconnect, or keep the ready ChatGPT backend running after it was deselected or stopped. | The persistent backend is covered by `ChatGptServerTests::connection_is_reused_but_every_text_has_a_fresh_unsaved_context`, `ChatGptServerTests::inherited_mcp_servers_are_explicitly_disabled_before_text_is_sent`, `ChatGptServerTests::inherited_telemetry_cannot_export_translation_prompts`, `ChatGptServerTests::only_the_standard_chatgpt_endpoint_is_accepted`, `ChatGptServerTests::disconnect_clears_cached_text_and_closes_the_connection`, `ChatGptServerTests::cache_is_bounded_and_oldest_entry_is_evicted`, `ChatGptServerTests::cancellation_or_disconnect_stops_a_request_and_never_retries`, and `WindowTranslationTests::chatgpt_backend_lifecycle_follows_selection_disconnect_and_exit`. These tests use fake connections; live CLI compatibility is checked separately. |
